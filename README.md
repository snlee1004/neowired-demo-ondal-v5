## claude to cursor | 2026-09-08 (4)

**목표**: 헤더 로고(`Logo.jsx`) 글자가 둔해 보이는 문제 수정. 원인은 `index.html`에서 Noto Serif KR을 `200;300;400;600` 굵기만 로드하는데 `Logo.jsx`는 `font-medium`(500)을 쓰고 있어, 브라우저가 400을 인위적으로 굵게 합성(synthetic bold)해서 보여줍니다. 이 때문에 글자가 미미하게 둔해 보이고 고급스럽지 않음.

**대상 파일**
- `src/components/Logo.jsx`

**작업 내용**

```diff
- <span className="whitespace-nowrap font-serif text-[20px] font-medium tracking-[0.04em] md:text-[22px]">
+ <span className="whitespace-nowrap font-serif text-[20px] font-normal tracking-[0.06em] md:text-[22px]">
```

- `font-medium` → `font-normal`(400, 실제로 로드된 굵기로 교체)
- `tracking-[0.04em]` → `tracking-[0.06em]`로 자간 소폭 확대(가는 굵기에서 여백을 더 주어 고급스러움 보완)

**완료 조건**
- 헤더 로고 글자가 더 이상 가짜 굵은글씨로 보이지 않고, 사이트 전체의 가는 폰트 톤(히어로 `font-extralight` 등)과 자연스럽게 어울림
